# D-FINE Intelligent Surveillance Video Compression

## Project Overview
This project presents a deep learning-based intelligent surveillance video compression system using D-FINE object detection and adaptive motion estimation.

## Objectives
- Detect important objects in surveillance videos.
- Improve video compression efficiency.
- Reduce video storage requirements.
- Maintain video quality.

## Technologies Used
- Python 3.11.9
- D-FINE Object Detection
- Deep Learning
- Computer Vision
- OpenCV
